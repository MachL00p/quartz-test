## Color code
  #AAAAAA - Naissance -> 0ère scolarité
  #BBBBBB - 1ère scolarité -> école primaire
  #CCCCCC - école primaire -> collège
  #DDDDDD - collège -> lycée
  #EEEEEE - lycée -> études supérieures
